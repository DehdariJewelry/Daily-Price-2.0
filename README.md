# وب‌اپ پوستر قیمت طلا و سکه ده‌داری

نسخه آماده انتشار روی **GitHub Pages**. رابط کاربری و تصویر پایه پوستر داخل `index.html` قرار دارند؛ برای اجرای خود اپ به سرور یا نصب وابستگی نیاز نیست.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید.

## انتشار با GitHub Pages

1. در GitHub یک مخزن جدید (Repository) بسازید.
2. فایل‌های این پوشه را در ریشه مخزن بارگذاری کنید؛ نام فایل اصلی باید `index.html` باشد.
3. وارد **Settings → Pages** شوید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب کرده و **Save** را بزنید.
6. پس از پایان انتشار، آدرس وب‌اپ در همان صفحه Pages نمایش داده می‌شود.

## نکته‌ها

- تنظیمات ظاهری در مرورگر با `localStorage` ذخیره می‌شوند؛ این تنظیمات بین مرورگرها یا دستگاه‌های مختلف همگام‌سازی نمی‌شوند.
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ در صورت نبود اینترنت، فونت جایگزین مرورگر استفاده خواهد شد.
- تغییر فضای پوستر در حالت خودکار با ساعت دستگاه کاربر انجام می‌شود. برای نتیجه درست، ساعت و منطقه زمانی دستگاه باید صحیح باشد.
- این نسخه یک وب‌اپ مستقلِ سمت مرورگر است و برای میزبانی روی GitHub Pages به Cloudflare Worker نیاز ندارد.
